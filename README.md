# PolyStrike — grywalny prototyp

## Uruchomienie

1. Otwórz terminal w tym folderze.
2. Wykonaj `pnpm install`.
3. Wykonaj `pnpm start`.
4. Otwórz `http://localhost:3000` w jednej lub kilku kartach przeglądarki.

## Sterowanie

- `WASD` — ruch
- `Shift` — sprint
- mysz — celowanie
- lewy przycisk myszy — strzał

Prototyp uruchamia trzy boty treningowe. Pierwszy gracz z 15 eliminacjami wygrywa.
